# Presentation Icons

발표용으로 직접 만든 단순 SVG 아이콘 모음이다. 공식 브랜드 아이콘이 애매하거나, 메인 아키텍처 장표에서 텍스트 라벨만으로는 심심한 컴포넌트를 빠르게 표현하기 위해 만들었다.

## 파일

- [karpenter-controller.svg](./karpenter-controller.svg)
- [metrics-server.svg](./metrics-server.svg)
- [aws-load-balancer-controller.svg](./aws-load-balancer-controller.svg)

## 사용 가이드

- 메인 장표에서는 이 아이콘들을 `플랫폼 / 클러스터 애드온` 구역에만 배치한다.
- `metrics-server`, `AWS Load Balancer Controller`는 공식 서비스 로고보다 설명용 배지가 더 적합하다.
- `Karpenter Controller`는 노드풀이 아니라 컨트롤러라는 점을 보여주기 위해 별도 아이콘으로 둔다.
